# Порт мода на Яндекс Музыку 5.122.0 (moro/dev122) — что изменилось против 5.121.2

Дата: 2026-10-03. Ветка `moro/dev122` (от моро/dev121 + чистый свап app-дерева на ваниль 5.122.0).
Итог: e2e 101/0, negative 20/0, structural + win structural ALL PASS.

## Главное отличие 5.122: полная перенумерация webpack module ID

Пересечение с 5.121.2 — **116 модулей из ~2510 (5%)**; у 119↔120↔121 было 94–95%.
Сменился сам алгоритм генерации ID у сборщика. Вся методика «пересадка модуля по
стабильному ID» (docs/PORT-5.121.md) мертва. Единственный путь — **контент-маппинг**:
ваниль-база + хирургическая дельта, имена переменных НЕ доверять (коллидируют между
эпохами: в 5.119 `o`=jsx, в ванили-122 `o`=mobx — верить только контенту/экспортам).

## Методика порта (что реально сработало)

1. **Чистый свап app-дерева** на ваниль (заодно уходит «смесь эпох» 5.120/5.121).
2. **Стор-чанк (4927)**: ваниль-122 + дельта — 15 модал-полей `r8.q` в ModalsModel,
   эксперимент-оверрайды (getExperiment/checkExperiment читают
   `window.DEFAULT_MUSIC_EXPERIMENT_OVERRIDES`), модель SyncLyrics мода (lrclib)

   ⚠️ Непереведённая ссылка типа в полях модели роняет mobx: `r._subType.validate

5. **Тайтлбар (layout-b2ad478f)**: трансплантат TitleBar-модуля (11517→2579) +

## Инструменты (живут в temp/, не в репо)

- `truecheck*.mjs` — живые экспорты реестра через in-page `__req` (webpack
  chunk-trick) + babel-анализ доступов с фильтром затенения. Главный верификатор.
- `fiberprobe.mjs` — читает пойманную ошибку из стейта error-баундари (React
  prod глотает всё молча). Показывает message+stack.
- Throw-site патч #130 в react-чанке асара — захват props падающего элемента
  (className/data-test-id) прямо в момент броска. После отладки удалить.
- `opsapply.py` — применение диф-операций с явными якорями (merge-регионы
  `apply_delta.py` дублируют середину — не использовать merge на минифицированном).
- `bulkbind.mjs` — пакетное лечение биндингов по контенту + live-верификация.

## Ловушки 5.122 (все пойманы живьём)

1. **Логин-скрин не шлёт `desktop:application:ready`** → 90с-таймаут форка
   рестартовал приложение в safe-mode бесконечно. Фикс: перед рестартом
   executeJavaScript-проба innerText (живой логин-скрин = скип, пустой = рестарт).
2. **Upstream мод-канал** (ru-node-1.pulsesync.dev) предлагает сборки под старые
   версии ЯМ — нажатие «Обновить» откатывает порт. Канал заглушен:
   DOWNLOAD/INSTALL_MOD_UPDATE = no-op, плашка suppressed.
3. **display-metrics-changed** от появления меню-бара при ховере верха экрана
   сносил окно нотча на ровном месте → rebuild только при реальной смене дисплеев.
4. **Окно гидрации**: после SPA-навигации на /settings первые ~3с виден
   пререндренный ванильный HTML (без мод-пунктов) — это НЕ потеря, проверки
   должны поллить пункт.
5. **Вин-CDP**: `prlctl exec` стартует процессы в сессии 0 (окно невидимо
   пользователю!) — только `PsExec -i 1` или запуск руками. Тесты «по невидимому
   инстансу» = проверка фантазий.
