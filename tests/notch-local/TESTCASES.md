# Тест-кейсы нотч-плеера

Запуск на цитрусе (все тесты — только там):
```
ssh -f -N -L 9223:127.0.0.1:9222 m@citrus          # туннель CDP
NOTCH_CDP=http://127.0.0.1:9223 node tests/notch-local/e2e.mjs
NOTCH_CDP=http://127.0.0.1:9223 node tests/notch-local/e2e-negative.mjs
node tests/notch/structural.test.mjs                # без приложения
```

## e2e-negative.mjs — выключенные состояния и конфигурация

| # | Сценарий | Ожидание |
|---|---|---|
| N1 | Настройка выключена, жмём тогл | Окно НЕ создаётся |
| N2 | Включаем настройку + тогл | Окно есть, кнопка в тайтл-баре видна |
| N3 | Свёрнутый нотч | Капсула: обложка + эквалайзер, панель скрыта (opacity 0) |
| N4a | showShuffleRepeat=off | Кнопок шаффл/повтор нет |
| N4b | showShuffleRepeat=on (на лету) | Кнопки появились без пересоздания окна |
| N5a | «Всегда временные метки» off | Метки opacity 0 (только ховер) |
| N5b | on | Метки видны всегда |
| N6 | Плеер idle, открываем меню | Меню открывается, рендер не падает |
| N7 | После закрытия меню | Стиль-невидимка снят — родное меню основного окна работает |
| N8 | Двойной тогл off→on | Количество окон не растёт (нет дублей) |
| N9 | display: primary → all | Окна пересобираются, количество то же |
| N10 | Выключение настройки | Окно закрыто И кнопка тайтл-бара исчезла |

## e2e-fullstack.mjs + run-fullstack.sh — весь стек, изолированные фазы

Каждая фаза — свой процесс на свежем приложении (драйвер сам перезапускает),
при сбое — один повтор (живое приложение меняет треки/тайминги):

| Фаза | Что проверяет |
|---|---|
| menu | меню открывается, пункты с иконками, стиль-невидимка не залип |
| windows | Show lyrics / Open queue / Sound settings / Trailer / Track details → окно в основном (пункта нет у трека — SKIP) |
| queue | Play next / Add to the end → очередь +1 |
| nav | Go to track / View album / Go to artist → переход |
| share | сабменю Share → Copy link кладёт URL в буфер цитруса (проверка через ssh pbpaste) |
| playlists | сабменю Add to playlist открывается, клик по пункту; полный список — ленивый лоадер приложения (тёплое = 12, холодное = Create playlist) |
| links | название → /album/track + панель, артист → /artist |
| volume | колесо над артом уменьшает громкость, HUD гаснет |
| pin | жёлтый, держит при уходе курсора, открепил — свернулась |
| checkboxes | Like / Repeat — скрытое исполнение, состояние меняется, потом возвращается |

Запуск: `NOTCH_CDP=http://127.0.0.1:9223 bash tests/notch-local/run-fullstack.sh` (~5–7 минут).
