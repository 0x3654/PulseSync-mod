# Установка PulseSync-mod на Windows (Яндекс Музыка 5.121.x)

## Что нужно
- установленный чистый клиент Яндекс Музыки 5.121.x (Windows x64);
- распакованный пакет мода: `mod-5.121-win.zip` → рядом лежат
  `install-mod-windows.ps1`, `README-WIN.md` и каталог `5.121\` с артефактами.

## Установка
1. Закройте Яндекс Музыку (инсталлер убьёт процесс сам, если она запущена).
2. Откройте PowerShell в папке пакета и выполните:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\install-mod-windows.ps1
   ```

   Если клиент стоит в нестандартном месте — добавьте
   `-InstallDir "C:\путь\к\папке\клиента"` (папка, где лежит `resources\app.asar`).
3. Запустите Яндекс Музыку. Готово.

Инсталлер сам: находит клиент, бэкапит оригиналы (`resources\app.asar.orig` +
исходный integrity-хеш), подменяет `app.asar` и `app.asar.unpacked`,
проверяет sha256 по manifest.json и патчит хеш целостности asar внутри exe
(тот же RCDATA-метод, что у тулсета: `bypass-asar-integrity`).

## Откат
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-mod-windows.ps1 -Uninstall
```
Вернёт оригинальный asar, unpacked и integrity-хеш exe.

## Обновление мода поверх мода
Просто запустите инсталлер нового пакета ещё раз: оригинальные бэкапы не
перезаписываются, ставится свежий asar + хеш.

## Заметки
- после патча exe его цифровая подпись Яндекса становится недействительной —
  это норма для локально-модифицированного бинарника; SmartScreen/антивирус
  изредка могут ругаться (тогда добавить папку клиента в исключения);
- автообновление клиента Яндузы перезапишет мод — после обновления клиента
  поставьте пакет заново (или откатитесь и обновитесь чистым клиентом);
- нотч-плеер — фича macOS; на Windows работают остальные части мода
  (мини-плеер, лайки/лирика, настройки, загрузки и т.д.).
